# ☁️ AWS Project 2 – EC2 Server Commander

A complete AWS EC2 implementation project demonstrating secure cloud server deployment using Amazon EC2.

---

## 📌 Project Overview

This project covers the complete lifecycle of deploying an Amazon EC2 instance from launch to termination while following AWS security and cost optimization best practices.

The project includes:

- EC2 Instance Launch
- Key Pair Creation
- Security Groups Configuration
- SSH Connection
- Nginx Installation
- Custom Web Page Deployment
- Live Server Verification
- AWS Shared Responsibility Model
- Cost Optimization
- CloudWatch Billing Alarm
- IAM Roles
- User Data Automation
- AWS CLI Commands
